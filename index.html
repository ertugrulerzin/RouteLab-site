RouteLab

A network engineering toolkit for Android, iPhone, iPad, Windows and Mac. Diagnose networks, inspect routing, audit services and move files between local, remote and cloud storage from one application.

What RouteLab does

Network diagnostics

Ping, traceroute, DNS, Whois, HTTP/TLS checks, port and network scans, routing lookups and engineering calculators.

Remote access

Work with SSH, SFTP, SMB and FTP connections that you own or are authorized to administer.

Dual-pane File Explorer

Select and copy files between local storage, remote servers, Google Drive, Dropbox and Box. Transfers happen only when the user starts them.

Why RouteLab requests Google Drive access

Google Drive connection is optional. If enabled, RouteLab requests permission to view and manage Drive files so its dual-pane File Explorer can display the complete folder hierarchy and perform user-requested open, upload, download, copy, rename, create and delete operations. Drive data is used only for these visible file-management features.

Drive file contents and OAuth credentials are processed by the installed application and are not uploaded to a RouteLab-operated server. A selected file is transferred to local storage or another connected provider only after the user explicitly starts that operation.
